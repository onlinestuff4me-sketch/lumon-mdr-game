Every number in the onboarding plan, with a lever on it. Nothing here is implemented yet — tune it first, then it gets built. The specimen windows and the pulse timeline are live: they run the same motion the game runs, at whatever amplitude and timing you set below.

STAGE 1

One temper, one group

—

Nothing is hidden. One group per screen, already moving, one full-width bin, no clock and no probe. What is being taught is not a gesture — it is what each temper looks like, learned by doing it rather than by reading about it. Three screens per temper because recognition needs repetition in different places on the board.

Specimens run at stage 1 amplitude — drag the subtlety lever and they answer.

STAGE 2

Two tempers, two bins

—

The first discrimination, and the first time a wrong answer is possible. Pairings are ordered so the easy one comes first and the two genuinely confusable pairs — dread against malice, frolic against malice — come last.

STAGE 3

Four tempers, four bins

—

The full deck, one group per temper, still all visible and still no clock. The last step before motion starts hiding.

RULES

Applying to every orientation screen

Generous selection The real game needs 4 digits inside the box (MIN_CAPTURE). Orientation sets it to 1, so dragging over any part of a group lifts the whole thing. A new player should never be told that their correct instinct was a wrong box.
Ceremony cost At full ceremony every one of these screens ends in a 100% banner, an addendum and a NEXT FILE button. That is 21 interruptions in what should feel like one continuous sequence, and 21 extra rows in an archive that is meant to hold secrets, not a progress bar.
PROBE

Motion that hides

1 FILE

One screen, one group, one bin. The group no longer stays visible — it breathes, surfacing for a moment and sinking back. The player's instinct is to tap the moving digits and box them; here that is honoured and then redirected, because the first touch summons the lens instead of the marquee.

The pulse

The handover

Why the lens lingers Reaching for a box and getting a magnifier is jarring by design — that is the point at which a new mechanic announces itself. The linger and the shrink are what turn it from a glitch into a tool: it stays long enough to be seen, then closes down with a lifecycle of its own.
ACT III

One new rule at a time

—

Act III's difficulty is currently two continuous dials — clock down, motion damped — which only makes it the same task, tighter. These mechanics make it a different task, and each gets the same three beats orientation uses: taught in isolation, used once, then part of the world.

The fifth temper

The one exception Every other mechanic gets a file that explains it, because a rule you cannot learn is just an unfair one. The fifth temper is the opposite case — its entire value is that nothing explains it. No coach line, no handbook entry, no teaching file. It costs a scatter to try and nothing to leave alone, so a player who never works it out loses only the secret. Its one acknowledgement is an archive row with no file code that stays SEALED forever.
